# Changelog

All notable changes to this project are documented in this file.

## 0.2.0 — 2026-09-22

The agentic LLM auditor: point opsaudit at any model (tabular classifier, chat model, RAG pipeline) and get an adaptive audit. The deterministic v0.1 core is untouched — all v0.1 tests stay green. Includes everything listed under 0.1.1 (Unreleased) below.

### Added

- **Phase 5 — reports, RMF integration, release** (`opsaudit.reports`): `AuditReport` assembled deterministically from campaign evidence (executive summary as template fill from numbers, never LLM prose; findings table; methodology with judge rubrics, prompt versions, and calibration scores; honest limitations; reproducibility block with seed, package version, git SHA, and target description); Markdown + standalone-HTML renders; `save_agentic_report` writing `.md`/`.html`/`.json`. Report verdict `FINDINGS WARRANT REVIEW`/`NO MATERIAL FINDINGS` at a heuristic flagging threshold (default 0.2, printed next to the verdict — not a significance test). NIST AI RMF 1.0 mappings (`MEASURE 2.11`, `2.1`, `2.3`, `2.13`, `MAP 5.1`, `MAP 1.1`, function-level `GOVERN`/`MANAGE`) framed as evidence contributions, each with documented limits (`docs/RMF_MAPPINGS.md`). 22 tests in `tests/test_reports.py` (canned fixtures, no LLM). Acceptance demo `examples/agentic-audit-demo/phase5_demo.py`: scripted 3-target run (tabular + text + RAG) where the fixed v0.1 battery misses a planted `employment_type` disparity and the agentic campaign finds it (gap 1.000), plus tone and refusal gaps in text outputs that v0.1 cannot measure. Design notes in `docs/agentic-auditor-phase5.md`.
- **Phase 4 — judges + calibration** (`opsaudit.judges`, `opsaudit.calibration`): `StereotypeJudge`, `RefusalJudge`, `ToneJudge` turn unstructured text into labels via short JSON-only prompts (one retry on empty, then `unscored` — a label is never invented); versioned prompt templates with the version in every `judge_id`. HARD RULE: judges never touch numbers — all statistics live in deterministic `aggregate` code. `CalibrationHarness` measures judge-vs-human agreement (accuracy, Cohen's kappa, per-label precision/recall, confusion) with PASS/FAIL at a configurable kappa threshold (default 0.6); `AuditCampaign` rejects uncalibrated judges unless the operator passes an explicit `allow_uncalibrated=True`, logged as evidence. Synthetic starter datasets (~40 items, marked synthetic). 40 tests in `tests/test_judges.py` + `tests/test_calibration.py`. Design notes in `docs/agentic-auditor-phase4.md`.
- **Phase 3 — agentic planner loop** (`opsaudit.agents`): `AuditPlanner` turns a brief plus compact numeric round summaries into JSON `ProbeSpec`s (short prompts, one retry on empty, malformed output ends the campaign with a logged reason); `Budget`/`BudgetTracker` enforce max probes/rounds/cost plus a deterministic flat-findings stopping rule; `ResponseCache` (SHA-256, memory + JSON file) so identical prompts/rows are never re-queried; `AuditCampaign` runs plan → probe → observe → replan with pair-preserving batch caps; same brief + seed reproduces the same campaign. 22 tests in `tests/test_agents.py`. Design notes in `docs/agentic-auditor-phase3.md`.
- **Phase 2 — probe generators** (`opsaudit.probes`): symmetric counterfactual pairs with `check_symmetry`, adversarial boundary probes, metamorphic relations with deterministic evaluation, and an LLM-assisted proposer treated as untrusted (candidates validated, invalid discarded with reasons). 32 tests in `tests/test_probes.py`. Design notes in `docs/agentic-auditor-phase2.md`.
- **Phase 1 — target adapters + evidence log** (`opsaudit.targets`, `opsaudit/evidence.py`): `Target` ABC with HuggingFace, OpenAI-compatible, Ollama Cloud, tabular, and RAG adapters; append-only JSONL evidence transcript. 51 tests. Design notes in `docs/agentic-auditor-phase1.md`.

## 0.1.1 — Unreleased

### Added

- Agentic auditor Phase 4: LLM judges + calibration (`opsaudit.judges`, `opsaudit.calibration`) — `StereotypeJudge`, `RefusalJudge`, and `ToneJudge` turn unstructured text into labels via short JSON-only prompts (one retry on empty, then `unscored` — a label is never invented); prompt templates are versioned and the `judge_id` in every score includes the version. HARD RULE: judges never touch numbers — all statistics live in deterministic `aggregate` code (group rates, gaps, ordinal means). `CalibrationHarness` measures judge-vs-human agreement (accuracy, Cohen's kappa, per-label precision/recall, confusion) with a PASS/FAIL recommendation at a configurable kappa threshold (default 0.6); FAIL prints a loud warning. `AuditCampaign` accepts optional `judges` (off by default) and rejects uncalibrated judges unless the operator passes an explicit `allow_uncalibrated=True`, logged as evidence. Synthetic hand-written starter datasets (~40 items) ship so the harness runs on day one — marked synthetic; production use needs real human labels. Worked demo in `examples/agentic-audit-demo/phase4_demo.py` (scripted judges calibrate at kappa 1.0; a deliberately constant judge FAILs at 0.0; a planted tone gap is caught via judge labels). 39 tests in `tests/test_judges.py` + `tests/test_calibration.py`, including hand-computed kappa values. Design notes in `docs/agentic-auditor-phase4.md`.
- Agentic auditor Phase 3: the adaptive planner loop (`opsaudit.agents`) — `AuditPlanner` turns an audit brief plus compact numeric round summaries into JSON `ProbeSpec`s (short prompts, one retry on empty, malformed output ends the campaign with a logged reason instead of crashing); `Budget`/`BudgetTracker` enforce max probes/rounds/cost plus a deterministic flat-findings stopping rule; `ResponseCache` (SHA-256 keys, memory + JSON file) ensures identical prompts/rows are never re-queried; `AuditCampaign` runs plan → probe → observe → replan, capping batches to the remaining budget without splitting counterfactual pairs or metamorphic groups, and computes deterministic round summaries (counterfactual gaps, adversarial error rates, metamorphic violation rates). Same brief + seed reproduces the same campaign. Worked demo in `examples/agentic-audit-demo/phase3_demo.py` (scripted planner drills broad group sweep → FT-vs-temp → robustness check → self-stop); 22 tests in `tests/test_agents.py` (drill-down, budget/flat/planner stops, seed reproducibility, cache dedup, graceful malformed-JSON handling). Design notes in `docs/agentic-auditor-phase3.md`.
- Agentic auditor Phase 2: deterministic probe generators (`opsaudit.probes`) — symmetric counterfactual pairs (tabular + text-template modes) with a `check_symmetry` verifier, adversarial boundary probes (extreme numerics, unseen categories, null rows; empty/whitespace/very-long/unicode/ambiguous/prompt-injection phrasings for text), metamorphic source/follow-up pairs with five builtin relations and an `evaluate_metamorphic` checker, and an LLM-assisted proposer that treats the model as untrusted (every candidate validated by the deterministic invariants; invalid ones discarded with reasons). `Probe`/`ProbeBatch` with target-facing converters (`text_prompts`, `rows`, `to_dataframe`) and evidence-log events. Worked demo in `examples/agentic-audit-demo/phase2_demo.py` (planted disparity caught by the real `audit_disparities`); 32 tests in `tests/test_probes.py`, including fuzzed symmetry property tests. Design notes in `docs/agentic-auditor-phase2.md`.
- Synthetic data auditor (`opsaudit.synthetics` + `opsaudit audit-synthetic` CLI): three-axis go/no-go evaluation of synthetic datasets against their source data — statistical fidelity (per-column KS/TVD, correlation drift, marginal coverage, support-aware `vanished_categories` escalation), privacy attack-surface probe (distance-ratio risk, memorization rate, exact-duplicate excess over chance), and bias amplification via the real `audit_disparities` on both frames with bootstrap-CI separation guards. YAML config with per-axis threshold overrides; JSON report with provenance block; exits 0/1/2 for pass/fail/review. Methodology and limitations in `docs/SYNTHETICS.md`; worked UCI Adult demo in `examples/synthetic-audit-demo/` (devcontainer pre-fetches the dataset); 33 tests in `tests/test_synthetics.py`.
- Flat YAML audit-context manifests, preserved in Markdown, HTML, and JSON audit evidence.
- Configurable minimum-group-size review conditions and an all-negative-decision review warning.
- Optional, capped, deterministic stratified bootstrap confidence intervals.
- Three-state deployment-gate status: `PASS` (exit 0), `FAIL` (exit 1), and `REVIEW` (exit 2).
- Repeated `--group` options for intersectional group labels.
- Operational audit playbook, demo script, and v0.1.1 evidence-quality design documentation.
- Tamper-evident provenance trail: every `audit` run embeds a `provenance` block in the report JSON (input SHA-256, row count, code version and git SHA, full resolved arguments, seed, UTC timestamp, Python version, gate verdict); `generate` writes a provenance sidecar next to its CSV. New `opsaudit verify` command recomputes the data hash, checks the report body hash and sign-off chain, and deterministically re-runs the audit to confirm recorded metrics and gate status (exit 0 = verified, 1 = tampered). New `opsaudit signoff` command appends hash-chained human review records (approve/reject) — the escalation point for REVIEW gates — and refuses to sign tampered reports. Full design, threat model, and real-data validation in `docs/PROVENANCE.md`.
- Disparity-gate GitHub Action (`.github/actions/disparity-gate`): reusable composite action that runs the gate on PRs touching model code/data, blocks the merge on threshold breach, posts the verdict with evidence as a PR comment, uploads the verdict + report artifact, and appends every verdict as JSONL to the append-only `opsaudit-audit-log` branch (survives force-pushes to PR branches; tradeoffs documented in README). Backed by a new `opsaudit.gate_ci` module and `opsaudit gate-run` CLI (`.opsaudit-gate.yml` config: audit spec, threshold overrides, `fail_mode: block|advisory`, `review: block|pass`; exits 0/1/2). The repo dogfoods the gate on its own PRs (`.github/workflows/disparity-gate.yml`); `examples/gate-consumer/` is a complete, deliberately-failing adoption example.

## 0.1.0 — 2026-09-18

### Added

- Binary group-disparity metrics for selection rate, demographic parity difference, disparate impact ratio, TPR gap, FPR gap, precision, and accuracy.
- Seeded synthetic dispatch and warehouse-staffing scenarios.
- Markdown, HTML, and JSON audit reports with function-level NIST AI RMF mapping.
- A CI-friendly deployment gate with YAML threshold overrides.
- `opsaudit generate`, `opsaudit audit`, and `opsaudit gate` commands.
- Test coverage for metrics, data generation, reports, gate behavior, and CLI workflows.

### Scope boundaries

- No model training, dashboard, web application, drift monitoring, telemetry, real company data, or runtime network calls.
